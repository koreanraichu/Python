# 개요
생물정보학 관련된 것들 중에 할 수 있는 게 뭐가 있을까... 하고 제미나이랑 티키타카 하다가 시작했습니다. 시작은 바이러스였지만 나중가면 혹시 모르죠. 세균이나 사람 단백질같은 거 할 지도... 

근데 이건 규모가 작아도 너무 작은데... 프로젝트라고 불러도 되나? 

## 프로젝트 정보
- 인원: 1인(개인 프로젝트)
- 버전: 3.10(TF_base)
- 설치할 것들: Biopython, MUSCLE(clustalw도 가능합니다. 코드에 있는 경로만 바꿔주세요.)
- 데이터 리소스: NCBI(Entrez로 갖고옴)
- 개발 환경: MacOS(14.7.6) (얘가 뭐 그렇게 OS타고 그럴 애는 아닙니다. MUSCLE이나 clustalW 경로는 바뀌겠지만.)
