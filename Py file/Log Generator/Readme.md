# 📊 이벤트 로그 생성 및 분석 시스템

## 개요
ChEMBL과 같은 가상의 화합물 DB를 상정하고 이벤트 생성을 진행했습니다. 
전공이 생물학쪽이다보니 쇼핑몰 GA4 이런게 확 와닿진 않아서 데드라인 지키려면+최대한 나사 덜 빠진걸로 제출하려면 제 전공이었던걸로 하는 게 나을 것 같다고 생각했습니다. 

DB다보니 이벤트가 그렇게 많지는 않습니다. 

원래 개발용으로 세팅해뒀던 리눅스가 골골거리는 관계로 아무 세팅이 안 된 윈도우에서 진행하였습니다. 
따라서 설치할 것은 matplotlib밖에 없습니다. (SQLite는 파이썬 설치할 때 따라옵니다) 

왜 SQL을 선택했느냐... 제가 할 줄 아는게 **그거밖에 없습니다.** NoSQL중에서는 MongoDB정도만 할 줄 아는데 걔는 쿼리까지 짜보진 않았습니다. 

### 이벤트 설계 룰 
1. 각 아이디는 6자리 정수형으로, 6자리가 안 될 경우 앞에 비는 만큼 0으로 채운다. (예: 1234->001234) 단, 저장할때는 그냥 저장한다. 
2. 화합물 정보 확인, 검색 결과 조회, csv 다운로드는 검색이 반드시 선행되어야 한다.
3. 같은 검색 아이디 내에서 csv 다운로드는 한 번만 하는 것으로 한다. (보통 필요한 것만 한번에 받죠...?) 단, 화합물 조회는 **검색 결과가 여러개라면** 여러 번 진행될 수 있다.
4. 같은 사용자가 여러 개의 화합물을 검색할 수 있다. 예를 들어서, 한 사용자가 아세트아미노펜과 이부프로펜을 검색할 수 있다. 물론 검색 결과와 후행 이벤트 역시 다른 검색 ID에 대해서는 별개이다.
5. 검색 ID가 같다면 검색어도 같다.
6. 에러가 생겼을 때는 이벤트 아이디와 검색 아이디, 유저 아이디, 이벤트 타입, 에러 타입만 기록된다.
7. 검색하다가 오타가 났을 경우, 결과 개수가 0이 된다. 
8. 오타때문에 결과가 0이 됐을 경우, 결과를 확인하고 재검색한다. 
9. 검색어별 검색 결과 개수는 항상 일정해야 한다. 
10. 이벤트 타입이 에러일 경우 최소한의 값(이벤트 아이디, 검색 아이디, 사용자 아이디, 이벤트 타입, 에러 타입, 타임스탬프)만 기록한다. 

## Schema
|컬럼명|데이터타입|제약조건|
|----|----|----|
|event_id|Integer|PK, AUTO INCREMENT|
|search_id|Integer|NOT NULL|
|user_id|Integer|NOT NULL|
|event_type|Text|NOT NULL|
|query|Text|없음|
|result_count|Integer|없음|
|compound_id|Integer|없음|
|error_type|Text|없음|
|timestamp|Datetime|없음|

1. event_id: 검색 세션 ID로, 1부터 시작합니다. PK이기때문에 Unique & !Null(=not null) 제약조건이 기본으로 붙고, Auto Increment가 붙어있습니다. 
2. search id: 사용자가 어떤 검색을 할 때 부여되는 아이디입니다. 검색과 그 검색에 따른 후행 이벤트에 수반되는 검색 아이디는 전부 동일합니다. 
3. user_id: DB에 접속해 정보를 열람한 사용자의 아이디입니다. 랜덤으로 6자리 숫자가 생성됩니다. 한 사용자가 여러 건의 검색(및 후행 이벤트)을 할 수 있습니다. 
4. event_type: search, result_view, chemical_view, download_csv, error 다섯가지입니다. 
5. query: 사용자의 검색어입니다. 중간중간에 일부러 오타를 넣었습니다. (룰 7, 8 관련)
6. result_count: 검색 결과 수입니다. 검색어에 오타가 났을 경우의 값은 0입니다. 
7. compound_id: 검색 결과 내 개별 화합물의 ID입니다. 원래는 순서값이 아니라 각 화합물에 따른 고유 아이디(ChEMBL ID같은 거)가 붙어있습니다. 
8. error_type: 에러가 터졌는데, 무슨 에러인가? 입니다. csv_download_failed랑 result_page_timeout 두개밖에 없습니다. 
9. timestamp: 이 이벤트가 발생한 시각입니다. 랜덤으로 생성했는데 시간 분포가 이븐하지 못합니다.
