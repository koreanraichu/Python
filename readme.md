# Readme.md
이 폴더에는 제가 파이썬으로 한 **모든**것들이 들어있습니다. 말 그대로 모든 것들이 말이죠. 
파일은 크게 py파일과 Jupyter파일 두 개로 나뉘어져 있습니다. 

## 폴더 일람
1. Py file: 그냥 평범한 파이썬 파일들입니다. 
   1. biopython: 예전에 cookbook 보면서 혼자 따라했던 것들이 들어있습니다. (전부 py)
      * Biopython을 설치하셔야 원만하게 구동됩니다. 
2. Jupyter file: Jupyter notebook으로 작업한 파일이 들어있습니다. (ipynb) 일단 뭘 설치해야 하는 게 많습니다. 
   1. .ipynb_checkpoints: 왜 있는지 모르겠습니다. 
   2. project: 개인적인 프로젝트들이 들어있습니다.
      1. EDA: 캐글이나 켐블(ChEMBL)같은데서 데이터 털어와서 나름 분석해본 것들입니다. 
      2. MSA: NCBI에서 바이러스 DNA 받아서 MSA를 진행한 파일들입니다. 
      3. Team project: 부트캠프때 팀프로젝트 했던 코드들입니다. 
      4. Project restriction enzyme: 제한효소 프로젝트입니다. 어... 일단 동작은 잘 해요. py, ipynb 둘 다 있는데 기본적인 수정은 ipynb에서 먼저 이루어집니다. py파일은 그냥 코드만 옮겨두는거라 잘 될지 안 될지 모르니 사용하실때도 ipynb를 사용해주세요. 
      5. Project wordcloud: 한글, 영어로 워드클라우드 만들어주는 코드입니다. 지금 실행이 잘 될지는 모르겠네요... 저도 안 돌려본 지 오래라... 
3. others: 각종 예제 데이터 및 출력 파일들이 정리되어 있습니다. 여기는 걍 넘어가셔도 됩니다. 
4. practice: 그냥 해봤던 것들이 들어있습니다. (py) 오래돼서 기억은 안 나는데 아마 실습용일겁니다.
